# CiteNet – mạng trích dẫn

Nhập một DOI, CiteNet dựng mạng trích dẫn 3D quanh bài báo đó: tài liệu tham khảo, các bài trích dẫn, tóm tắt, bản truy cập mở hợp pháp; phân loại thiết kế nghiên cứu (PubMed → từ khoá → OpenAlex) và chấm điểm sàng lọc độ tin cậy có ghi lý do.

**Dùng ngay:** https://drcuongntq-hash.github.io/citenet/

- Dữ liệu: OpenAlex (khoá API miễn phí tại openalex.org/settings/api) và PubMed E-utilities.
- Khoá API chỉ lưu trong trình duyệt của người dùng.
- Xuất RIS (Zotero/EndNote), CSV, JSON, danh sách link PDF mở.
- Trên điện thoại: mở link → Chia sẻ → "Thêm vào màn hình chính" để dùng như ứng dụng.

Điểm tin cậy là điểm sàng lọc tự động, không thay thế thẩm định GRADE hay công cụ nguy cơ sai lệch (RoB 2, ROBINS-I).
